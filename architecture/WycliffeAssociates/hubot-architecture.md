# hubot architecture

[WycliffeAssociates/hubot](https://github.com/WycliffeAssociates/hubot) — Bot for messaging.

bot is a chat bot built on the [Hubot][hubot] framework. It was initially generated by [generator-hubot][generator-hubot], and configured to be deployed on [Heroku][heroku] to get you up and running as quick as possible.
